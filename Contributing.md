# Contributing to AI-Security-Blog

Thank you for considering contributing! It’s researchers like you who help make the AI landscape safer for everyone.

## How Can I Contribute?

### 1. Reporting New AI Vulnerabilities
If you’ve discovered a new prompt injection technique or a security flaw in an AI framework, please:
* Open an **Issue** with the tag `new-research`.
* Provide a brief description and, if possible, a Proof of Concept (PoC).

### 2. Adding to the Blog
If you'd like to write a guest post or add a technical guide:
1. Fork the repo.
2. Create a new branch (`git checkout -b feature/new-blog-post`).
3. Add your Markdown file to the appropriate folder.
4. Ensure any code snippets are tested and commented.
5. Submit a **Pull Request**.

### 3. Improving Documentation
Found a typo or a broken link? Feel free to submit a quick PR!

## Style Guidelines
* **Clarity First:** Explain complex AI concepts in a way that a general Security Engineer can understand.
* **Code:** Please include a `requirements.txt` if your research requires specific Python libraries.
* **Citations:** Always credit original researchers or papers if you are summarizing existing work.

## Questions?
If you have questions, feel free to reach out by opening an issue or contacting me through my social links in the main README.
